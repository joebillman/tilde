# Tilde product spec

## 1. The problem

Typing Spanish on a US keyboard in Windows is awkward. The built-in options are
alt codes (`Alt+0233` for é), switching keyboard layouts (which moves other
keys), or copy and paste. Phones and Macs let you hold a key to get its accent;
Windows does not.

Existing Windows tools come close but miss in ways that matter for students
(details in `BACKGROUND.md`):

- PowerToys Quick Accent shows a picker of every language's accents and needs a second key to choose. It also needs admin rights to install.
- None of them maps `?` → `¿` and `!` → `¡` on the keys a learner would expect.
- None offers "pick Spanish, hold the key, done."

## 2. Who it is for

- **Students** typing Spanish assignments on school-issued Windows 11 laptops with US keyboards. They cannot install software themselves; the school pushes apps through Intune Company Portal.
- **School IT**, who must approve it. They care that it is small, needs no admin rights, makes no network connections, and does not record keystrokes.
- **Anyone** who types occasional Spanish on Windows.

## 3. Behavior rules

"Mapped character" means a character that has at least one variant in the
active language map (§4). "Mapped key press" means a key press that would type
a mapped character, taking Shift and Caps Lock into account.

**R1. Tap is untouched.** A mapped key press types its normal character
immediately, with no delay. If the key is released before the hold delay, that
is all that happens.

**R2. Hold replaces.** If the key is still down when the hold delay elapses
(default 500 ms), Tilde replaces the character just typed with its first
variant: `e` becomes `é`.

**R3. No repeats on mapped keys.** While a mapped key is held, the keyboard's
auto-repeat for that key is suppressed. Holding `e` never produces `eeee`.

**R4. Keep holding to cycle.** If the character has more than one variant,
then after each further cycle delay (default 600 ms) Tilde replaces what is
showing with the next item in this loop: variant 1, variant 2, ..., the
original character, then back to variant 1. For Spanish only `u` cycles:
`u` → `ú` → `ü` → `u` → `ú` ... Characters with one variant do not cycle; `é`
stays `é` however long the key is held.

**R5. Release commits.** Releasing the key keeps whatever is showing.

**R6. Another key commits.** Pressing any other key while holding commits what
is showing and that other key is then handled normally (it may start its own
hold).

**R7. Case follows the keyboard.** Shift or Caps Lock gives the capital:
holding Shift+`e` gives `É`. `¿` and `¡` come from holding `?` and `!`, which
on a US layout are Shift+`/` and Shift+`1`.

**R8. Shortcuts are untouched.** If Ctrl, Alt, or the Windows key is down,
Tilde ignores the key press entirely. `Ctrl+A`, `Alt+E`, and AltGr
combinations behave as if Tilde were not running.

**R9. Unmapped keys are untouched.** Every key that does not type a mapped
character behaves normally, including auto-repeat (Backspace, arrows, `x`...).

**R10. Focus change cancels.** If the foreground window changes while a key is
held, Tilde does nothing further for that hold. It must never type into a
window other than the one where the hold began.

**R11. Off means off.** When disabled from the tray, Tilde changes nothing
about typing.

**R12. Injected input is ignored.** Key events generated by software (Tilde's
own output, remote-control tools, on-screen keyboards) never start or affect a
hold.

## 4. Spanish map

| Typed | Variants, in order |
|---|---|
| `a` | `á` |
| `e` | `é` |
| `i` | `í` |
| `o` | `ó` |
| `u` | `ú`, `ü` |
| `n` | `ñ` |
| `?` | `¿` |
| `!` | `¡` |

Capitals follow automatically: `A` → `Á`, `U` → `Ú`, `Ü`, `N` → `Ñ`.

Every variant must be a single precomposed Unicode character (NFC), because
replacement sends exactly one Backspace.

## 5. Settings

Stored per user. All have defaults; the app works with no setup.

| Setting | Default | Allowed |
|---|---|---|
| Enabled | on | on / off |
| Language | Spanish | Spanish only in v1 |
| Hold delay | 500 ms | 300 (Short), 500 (Medium), 800 (Long) |
| Cycle delay | 600 ms | not exposed in the UI in v1 |
| Start with Windows | on | on / off |

## 6. Tray interface

Tilde has no main window. It shows a tray icon with this menu:

- **Enabled** (checkmark toggle). The icon is dimmed when disabled.
- **Language** → Spanish (checked).
- **Hold delay** → Short / Medium / Long.
- **Start with Windows** (checkmark toggle).
- **How to use** opens a small window showing the table from §4.
- **About** shows the version and the privacy statement from §8.
- **Exit**.

Double-clicking the icon toggles Enabled. On first run, show the How to use
window once.

## 7. Not in v1

- Other languages (French, German, Portuguese). The design must allow adding one as data, without code changes to the engine.
- A visual picker popup.
- Auto-correcting whole words (`tambien` → `también`). Considered and parked; see `BACKGROUND.md`.
- Mac or Linux versions.
- Per-app exclusion lists (planned for hardening; see `PLAN.md` M4).

## 8. Privacy promises

These are user-facing commitments and appear in the About window and the Store
listing. They are also hard rules for anyone changing the code.

- Tilde makes no network connections.
- Tilde does not record, store, or send anything you type.
- Tilde does not need administrator rights.
- The source code is public.

## 9. Known trade-offs

- **Mapped keys lose auto-repeat.** You cannot hold `a` to type `aaaa`, or `!` to type `!!!!`, while Tilde is enabled. This is the cost of R3.
- **Elevated apps are out of reach.** Windows hides keystrokes in apps running as administrator from non-elevated apps, so Tilde does nothing there.
- **Replacement relies on Backspace.** Where an app reacts to a typed letter by selecting or inserting extra text (browser address-bar autocomplete, some code editors), the result can be wrong. See `ARCHITECTURE.md` §8.
- **Games.** Holding a mapped key in a game would trigger a replacement. Until per-app exclusions exist, users disable Tilde from the tray.
